PAMELA GUTMAN PORTFOLIO: STUDIO HOMEPAGE CONCEPT v03
================================================

A homepage-first redesign for review, not an overhaul of your interior pages.
The existing Backup League console and resource pages are NOT changed.

Three files are needed to publish this draft:
  index.html
  assets/studio-home.css
  assets/backup-league-console-preview.webp

Upload these files into the matching GitHub paths in the EXISTING
pamelagutman/pamela-gutman-portfolio repository. Do not nest them under
a new portfolio_studio_home_v03 folder.

The console preview is an actual screenshot of the existing H.E.L.P.E.R.
terminal, cropped for the homepage; no fabricated mock-up is used.

WHAT CHANGED:
- Replaced busy homepage sections with four: hero, 2 featured projects,
  1 Field Notes story, and contact invitation.
- More natural, specific language and real images.
- Simplified visual hierarchy; retained the portal logo and clear nav.
- Homepage-only stylesheet, isolated from the rest of the website.
- Kept navigation links accessible with visible keyboard focus, contrast
  targets, semantic structure, and motion reduction.

IMPORTANT:
- Home page only. Other site pages retain their previous layouts.
- This is NOT a certified Section 508/WCAG audit. It needs human
  keyboard, screen-reader and assistive-technology validation before
  claiming compliance.
- Preview before upload to see whether the tone really sounds like Pam.
- Check publicly released descriptions and images for suitability.
